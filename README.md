# biometric_storage_kit

Independent DartNative biometric-protected secret storage. Version 0.1.0-dev.1.
Implementation is in progress; the template is not a functioning security plugin.

Original code: Apache-2.0. iOS uses FFI to Swift Keychain/LocalAuthentication;
Android uses FFI through C++ JNI to Kotlin Keystore/BiometricPrompt.

No Orb wallet, account, signing or recovery policy belongs in this package.
Publication has not been requested.
